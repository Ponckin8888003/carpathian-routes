# Карпатські маршрути

Вебсервіс планування туристичних маршрутів українськими Карпатами (навчальний проєкт).

Поточний етап (лабораторна 2.2): сторінки й маршрутизація (React Router).
Є головна, каталог із фільтрами в URL, сторінка вершини, локальні плани походів,
сторінки нового й редагування плану, обробка невідомих адрес. Чернетки планів
не зберігаються.

## Вимоги

Node.js 20.19+ або 22.12+, npm, Git. Маршрутизація: пакет `react-router` (фактична версія вказана в `package.json`, перевірити: `npm ls react-router`).

## Запуск

```bash
npm install
npm run dev
```

Адреса: http://localhost:5173

## Адреси для перевірки

- `/peaks?q=говерла&routes=1` — каталог із фільтрами
- `/peaks/hoverla` — деталі вершини
- `/plans` — демонстраційні плани
- `/plans/new?peakId=hoverla` — нова чернетка плану
- `/plans/plan-001/edit` — редагування плану
- `/unknown`, `/peaks/missing`, `/plans/missing/edit` — відсутні сторінки й записи

Обмеження: зміни в чернетках не зберігаються й скидаються при виході зі сторінки
або перезавантаженні. Для хостингу потрібне повернення `index.html` для клієнтських
маршрутів.

## Збірка

```bash
npm run build
npm run preview
```

Перегляд збірки: http://localhost:4173
