# Карпатські маршрути

Вебсервіс планування туристичних маршрутів українськими Карпатами (навчальний проєкт).

Поточний етап (лабораторна 1.2): компонентна архітектура. Є початкова сторінка
з каталогом вершин, спільні компоненти (оболонка, секція, кнопка, поле форми) і
макет форми плану походу. Збереження плану ще не реалізовано.

## Вимоги

Node.js 20.19+ або 22.12+, npm, Git.

## Запуск

```bash
npm install
npm run dev
```

Адреса: http://localhost:5173

## Збірка

```bash
npm run build
npm run preview
```

Перегляд збірки: http://localhost:4173
