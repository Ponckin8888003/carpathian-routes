# Карпатські маршрути

Вебсервіс планування туристичних маршрутів українськими Карпатами (навчальний проєкт).

Поточний етап (лабораторна 2.1): інтерактивний каталог. Можна фільтрувати
вершини, розгортати опис, вибирати вершину й готувати чернетку плану походу з
підсумком. Чернетка існує лише в пам’яті сторінки й не зберігається.

## Вимоги

Node.js 20.19+ або 22.12+, npm, Git.

## Запуск

```bash
npm install
npm run dev
```

Адреса: http://localhost:5173

## Збірка

```bash
npm run build
npm run preview
```

Перегляд збірки: http://localhost:4173
