# Карпатські маршрути

Вебсервіс планування туристичних маршрутів українськими Карпатами (навчальний проєкт).

Поточний етап (лабораторна 3.1): форми, перевірка та операції над даними.
Є головна, каталог із фільтрами в URL, сторінка вершини, а також створення,
перегляд, редагування й видалення планів походів з перевіркою полів. Список
планів має пошук, фільтр і сортування в адресі.

## Вимоги

Node.js 20.19+ або 22.12+, npm, Git. Маршрутизація: пакет `react-router` (фактична версія вказана в `package.json`, перевірити: `npm ls react-router`).

## Запуск

```bash
npm install
npm run dev
```

Адреса: http://localhost:5173

## Адреси для перевірки

- `/peaks?q=говерла&routes=1` — каталог із фільтрами
- `/peaks/hoverla` — деталі вершини
- `/plans?q=говерла&sort=date-desc` — список планів із умовами
- `/plans/new?peakId=hoverla` — нова чернетка плану
- `/plans/plan-001` — сторінка плану
- `/plans/plan-001/edit` — редагування плану
- `/unknown`, `/peaks/missing`, `/plans/missing/edit` — відсутні сторінки й записи

Обмеження: плани зберігаються лише в пам’яті застосунку. Після перезавантаження
сторінки повертаються початкові записи з `src/data/plans.js`; збереження між
сеансами буде додано в наступній роботі. Для хостингу потрібне повернення `index.html` для клієнтських
маршрутів.
